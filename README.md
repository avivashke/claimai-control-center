# 🛡️ ClaimAI Control Center | מערכת שליטה אחודה לניהול לקוחות ומוצר

מערכת שליטה ובקרה מתקדמת ואינטראקטיבית עבור חברת **ClaimAI**, המאחדת תחת קורת גג אחת את ניהול כל הלקוחות והלידים (CRM) לצד ניהול מפת הדרכים של המוצר, דרישות לקוח ותקלות שירות (Product & Delivery Control).

האפליקציה פותחה במיוחד לקראת העלאה ואירוח מהיר ב-**Netlify**, ומכילה תמיכה כפולה במסדי נתונים: מסד נתונים מקומי מהיר ופועל מיד בדפדפן (IndexedDB) לצד סכמת PostgreSQL/Supabase מוכנה לעבודה בענן.

## 🌟 יכולות המערכת העיקריות

### 1. 📊 סקירה כללית (Executive Overview Dashboard)
- מדדי מפתח (KPIs): סה"כ לקוחות ולידים (1,282), לידים דחופים, תקלות קריטיות, משימות מפת דרכים.
- חלוקת עומס משימות לפי לקוח (Workload & Progress): מעקב שוטף אחר פניות סוכנויות ולקוחות (ClaimAI Internal, Finkel Agency, Jamal Dabbah, Racheli Asraf, Randa, Shlomik kedem).
- תמונת מצב משפך לקוחות (1'st Lead, Follow-up, Meeting Scheduled, Important, Urgent, Adoption Monitoring, All-Good).
- תצוגה מהירה של תקלות קריטיות בטיפול.

### 2. 👥 ניהול לקוחות ומכירות (CRM)
- **מאגר של 1,282 לקוחות ולידים** טעון מראש מגיליונות המקור.
- סינון וחיפוש מתקדם: חיפוש לפי שם, חברה, טלפון, אימייל והערות; סינון לפי סטטוס וסוג עסק (סוכנות ביטוח, מוסך, שמאי, עורך דין ועוד).
- פעולות מהירות בשורה: חיוג טלפוני בלחיצה, שליחת וואטסאפ ישיר (`https://wa.me/972...`), שליחת מייל ועדכון סטטוס מיידי.
- ייצוא מהיר של נתוני ה-CRM לקובץ CSV/Excel.
- **פרופיל לקוח 360 (Client Drawer)**:
  - עריכת פרטי הלקוח, פרטי איש מחשוב וצוות, ונפח תביעות חודשי.
  - יומן הערות כרונולוגי עם חותמות זמן אוטומטיות.
  - **קישור ישיר למשימות מוצר ותקלות**: צפייה בכל התקלות ובקשות הפיצ'רים המשויכות ללקוח זה, ויצירת פניות חדשות ישירות מתוך הפרופיל!

### 3. ⚡ היום שלי (My Day - Action Center)
- מסך עבודה ממוקד לנציגים ומנהלים:
  - לידים הדורשים טיפול מיידי וחריגות SLA.
  - פגישות ודמואים שנקבעו (`Meeting Scheduled`).
  - לידים חשובים ומעקבים שוטפים.
- כפתורי פעולה מהירים לטיפול ישיר מתוך הרשימה.

### 4. 🚀 בקרה ומסירת פיתוח (Product & Delivery Control)
- **43 משימות פיתוח טעונות מראש** (10 תקלות ובאגים + 33 משימות מפת דרכים).
- תצוגת טבלה ותצוגת **לוח קנבן (Kanban Board)** לפי שלבי מסירה (Backlog → Open → In Progress → Done).
- סינון לפי לקוח/מקור, עדיפות (Critical, High, Medium, Low), וסטטוס.
- מגירת פירוט משימה (Ticket Drawer): פירוט תקלה, צעדים לשחזור, מודול, יעד שחרור (Next Sprint / Q1 2027), יומן הערות פיתוח וקישור לפרופיל הלקוח ב-CRM.
- יצירת פניות חדשות (תקלה או פיצ'ר) עם מזהים אוטומטיים (FX-xxx, RM-xxx).

### 5. ⚙️ דאטה-בייס והגדרות אירוח ב-Netlify
- **ארכיטקטורת מסד נתונים היברידית**:
  - **IndexedDB מקומי (Dexie.js)**: עובד מיד עם פתיחת האפליקציה, שומר את כל הנתונים, ההערות והשינויים בתוך הדפדפן ללא צורך בשום הגדרה מוקדמת.
  - **Supabase / PostgreSQL Cloud**: תמיכה מובנית בחיבור לענן על ידי הזנת URL ו-Key, או הגדרתם כמשתני סביבה ב-Netlify.
- סקריפטי SQL מוכנים בתיקיית `supabase/`:
  - `supabase/schema.sql` - הגדרת טבלאות, אינדקסים וחוקי RLS.
  - `supabase/seed.sql` - סקריפט מילוי נתונים ראשוניים.
- ייצוא גיבוי מלא של כל המערכת לקובץ JSON.
- אפשרות איפוס בלחיצה אחת לנתוני המקור מגיליונות ה-Google Sheets.

## 🚀 הרמה ואירוח ב-Netlify (Deployment)

הפרויקט מכיל קובץ `netlify.toml` מוגדר מראש:

```toml
[build]
  command = "npm run build"
  publish = "dist"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

### צעדי הפריסה:
1. היכנס לחשבון [Netlify](https://app.netlify.com).
2. לחץ על **"Add new site"** ← **"Import an existing project"**.
3. בחר ב-**GitHub** ובחר בריפו שלך: `avivashke/claimai-control-center`.
4. נטיפי תזהה אוטומטית את ההגדרות מקובץ `netlify.toml`:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
5. (אופציונלי) אם ברצונך לחבר את מסד הנתונים לענן Supabase, הוסף בלשונית **Environment variables**:
   - `VITE_SUPABASE_URL` = כתובת הפרויקט ב-Supabase
   - `VITE_SUPABASE_ANON_KEY` = המפתח הציבורי (anon key)
6. לחץ על **"Deploy site"** – האתר יעלה לאוויר תוך דקה!

## 🗄️ מבנה מסד הנתונים (Database Schema)

- **`crm_clients`**: לקוחות ולידים (מזהה, שם, חברה, סוג עסק, סטטוס, טלפון, אימייל, הערות, התראות).
- **`crm_contacts`**: אנשי קשר נוספים משויכים ללקוח.
- **`crm_activities`**: היסטוריית פעולות והערות.
- **`product_items`**: תקלות ובקשות מפת דרכים (קטגוריה, סוג, מודול, כותרת, עדיפות, סטטוס, לקוח משויך, תאריכי יעד).
