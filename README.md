# 🛡️ ClaimAI Control Center | מערכת שליטה אחודה לניהול לקוחות, מוצר ופורטלים

מערכת שליטה ובקרה מתקדמת ואינטראקטיבית עבור חברת **ClaimAI**, המאחדת תחת קורת גג אחת:
1. **ניהול לקוחות ומכירות (CRM)**
2. **ניהול מפת הדרכים של המוצר, דרישות לקוח ותקלות שירות (Product & Delivery Control)**
3. **סטודיו AI גנרטיבי לקליטת נתונים ויצירת טבלאות דינמיות (AI Table Studio)**
4. **פורטלים למשתמשים והרשאות עריכה/צפייה עם פרוטוקול התחברות Google Identity (OAuth 2.0)**

האפליקציה פותחה במיוחד לקראת העלאה ואירוח מהיר ב-**Netlify**, ומכילה תמיכה כפולה במסדי נתונים: מסד נתונים מקומי מהיר ופועל מיד בדפדפן (IndexedDB) לצד סכמת PostgreSQL/Supabase מוכנה לעבודה בענן.

## 🌟 יכולות המערכת העיקריות

### 1. 🔐 פורטלי משתמשים והרשאות Google OAuth
- **התחברות באמצעות חשבון Google:**
  - כפתור רשמי "המשך עם חשבון Google" מבוסס פרוטוקול Google Identity Services (OAuth 2.0).
  - שיוך אוטומטי של תפקידים לפי אימייל המשתמש.
- **פורטל אדמין (Admin Portal):**
  - לשונית ייעודית למנהלי המערכת לניהול כל חברי הצוות והמשתמשים.
  - כפתור "+ יצירת משתמש חדש והענקת הרשאות".
  - **הגדרת רמות גישה (Roles):**
    - **מנהל מערכת (Admin):** גישה מלאה לכל המודולים, הרשאת ניהול משתמשים, עריכת CRM, מוצר וטבלאות.
    - **עורך (Editor):** הרשאת עריכה ויצירה מלאה של לידים, תקלות וטבלאות, ללא גישה להגדרות ניהול משתמשים.
    - **פורטל צפייה בלבד (Viewer Portal):** גישת קריאה וצפייה בלבד! כפתורי הוספה, עריכה, מחיקה ושינוי סטטוסים מנוטרלים או מוסתרים.
  - מטריצת הרשאות מפורטת לכל משתמש: הרשאת עריכת CRM, הרשאת עריכת מוצר, הרשאת טבלאות AI והרשאת אדמין.
  - **סימולטור פורטלים בזמן אמת:** כפתורי מעבר מהיר בראש פורטל האדמין המאפשרים לבדוק בלחיצה אחת כיצד נראה הפורטל מנקודת מבטו של אדמין, עורך או צופה בלבד.

### 2. 🤖 סטודיו AI לקליטת נתוני לקוחות ויצירת טבלאות דינמיות

- **עיבוד בעזרת AI גנרטיבי:**
  - מנוע AI מובנה הפועל בדפדפן (ללא עלות וללא צורך במפתח).

## 🚀 הרמה ואירוח ב-Netlify (Deployment)

הפרויקט מכיל קובץ `netlify.toml` מוגדר מראש:

```toml
[build]
  command = "npm run build"
  publish = "dist"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

### צעדי הפריסה:
1. היכנס לחשבון [Netlify](https://app.netlify.com).
2. לחץ על **"Add new site"** ← **"Import an existing project"**.
3. בחר ב-**GitHub** ובחר בריפו שלך: `avivashke/claimai-control-center`.
4. נטיפי תזהה אוטומטית את ההגדרות מקובץ `netlify.toml`:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
5. (אופציונלי) הגדר משתני סביבה ב-Netlify:
   - `VITE_GOOGLE_CLIENT_ID` = מזהה ה-OAuth מ-Google Cloud Console
   - `VITE_SUPABASE_URL` = כתובת הפרויקט ב-Supabase (אם משתמשים בענן)
   - `VITE_SUPABASE_ANON_KEY` = המפתח הציבורי של Supabase
6. לחץ על **"Deploy site"** – האתר יעלה לאוויר תוך דקה!
